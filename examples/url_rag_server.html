Paste an English article URL. The server fetches it, extracts the readable text, splits it into token-budgeted chunks, embeds each chunk with MiniLM, and folds it into the accumulating LatentDb (re-ingesting the same URL will not grow the record count -- content-hash dedup collapses the repeat chunks).

    Type a free-text query and compare plain vector search against search_blended(), which fuses the same vector ranking with a lexical term-overlap ranking over the query's own words. The two score columns aren't on the same scale (cosine similarity vs. Reciprocal Rank Fusion) -- compare rank order, not the numbers.
